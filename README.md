## Selected public work

### Mission Zero Radar

**Signal triage for AI agents.**

A small decision layer for a recurring problem in agentic systems: an external signal appears — a new model, tool, competitor move, research finding or market event — but should it actually change what the agent is doing?

Mission Zero Radar turns that signal into a context-grounded verdict and a bounded next step.

Tested on a frozen evaluation set with **85% first-run holdout accuracy and 0% false `BUILD_NOW` decisions**.

→ [Mission Zero Radar](https://github.com/serhiitrofimov/mission-zero-radar)
